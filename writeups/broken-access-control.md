# Broken Access Control / IDOR — View Basket

## Overview

The View Basket challenge demonstrated an insecure direct object reference (IDOR) / broken-access-control issue.

## Testing

Browser Developer Tools were used to inspect network requests generated by basket functionality.

The request contained a basket identifier. The identifier was modified and the resulting server response was observed.

The application returned data associated with another basket, demonstrating insufficient server-side authorisation checks.

## Impact

Broken access control can expose information belonging to other users and, depending on the affected functionality, may also allow unauthorised modification or deletion of data.

## Recommended Mitigation

- Perform authorisation checks on the server for every protected resource.
- Verify that the requested resource belongs to the authenticated user.
- Do not rely on user-controlled identifiers as proof of authorisation.
- Log and monitor suspicious repeated access attempts.

## OWASP Classification

OWASP A01:2021 — Broken Access Control.
